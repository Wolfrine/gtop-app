**Approved visual character:** warm ivory/off-white background, muted sage and jade accents, deep green typography, generous whitespace, rounded but restrained surfaces, subtle depth, editorial display typography for prominent headings, clear modern sans-serif UI labels. Calm and contemporary; avoid generic educational clipart and overcrowded dashboards.

**Information architecture:** Practice, Answer Sheets, Progress; Admin only for authorized accounts. Quick/Custom Quiz, Live Quiz, Quiz Run, and Learning Lab remain under Practice. Answer Sheets is available to all signed-in roles, with private submissions and separate staff authorization for checking and release. Existing functional routes and saved data must be preserved.

**Implementation acceptance:** render and compare real authenticated pages in mobile and desktop viewports to these references; use actual data states, not the illustrative mockup metrics/content. Never treat a build alone or these still images as proof of visual fidelity.

This branch exists solely to give development agents the precise design references without changing production application code.
