Quick guide

Two ways to practise together

Choose a hosted live quiz or share a quiz run with friends.

Live Quiz

Join a scheduled quiz and follow the results.

  1. Tap Live Quizzes to view teacher-hosted sessions.
  2. Use the join code shared by the host.
  3. Answer the questions and review the leaderboard.
bolt Explore Live Quizzes

Quiz Run

Create a run and share the join code.

  1. Open Quiz Runs and create a lobby.
  2. Share the join code with friends or classmates.
  3. Start the run when everyone is ready.
