## The main finding

The useful common quality is a coherent relationship between **identity, content hierarchy and the job being performed**. These references achieve it in visibly different ways. DES uses typography and sculptural imagery; Trust uses a consistent drawn world and explanatory feedback; Primer uses precise alignment and predictable controls. A distinctive learning product does not need to make every screen behave like an immersive agency homepage.

For GTOP, the working hypothesis is to establish one recognizable family while allowing the public invitation, focused practice, exploratory labs and dense admin work to use different levels of expression. This is a direction to investigate in the next stages, not permission to choose a palette, copy a site or begin implementation.

## What “premium” means for this review

| Relationship to inspect | Positive evidence in the reference set | Common trap for GTOP |
|---|---|---|
| Focal point and reading order | DES creates a clear visual landmark; Brilliant pairs proposition and demonstration | Every card, number and button asking for equal attention |
| Typography and task | Linear uses limited, deliberate hierarchy; Primer makes row labels and values distinguishable | Huge display type in dense tools, or tiny metadata copied into learner content |
| Spacing and density | twks gives projects presence; Primer gives rows repeatable comparison structure | Equating more whitespace with better design regardless of the task |
| Colour and meaning | Bicycle connects coloured terms, objects and controls; Linear reserves accents | Colour used only to decorate cards, with inconsistent status meanings |
| Identity and consistency | DES’s related course objects; Trust’s matching type, drawings and controls | A generic component kit plus unrelated decorative illustrations |
| Motion and purpose | Trust ties an action to an explained consequence; Brilliant’s animated demonstration motivates a separate playback-control check | Long entrances on repeated visits, or motion that obscures the next action |
| Responsive composition | Bicycle retains reading measure and control proximity | Scaling a desktop screenshot down and calling it mobile design |

These are evaluator judgments grounded in the linked evidence. They are not a universal formula for what humans find attractive. The [human-appeal note](human-appeal.md) distinguishes visible observations, creator intent, expert awards and actual participant responses. No GTOP learner preference study has been conducted. The later mockup review should compare equal content and ask separately about initial attraction, understanding and willingness to use the screen repeatedly.

Action Plan R23 remains excluded. These questions set comparison criteria; they do not assert that GTOP currently passes or fails them.

## Motion conclusions

An entrance can communicate identity, a scroll sequence can pace a story, and a state transition can explain a result. Each needs its own evidence. We preserved normal-motion sequences, sampled frames, action timestamps, fast/reverse scroll attempts and a reduced-motion reload check. Controls were inspected separately.

The source recordings are available for replay. Frame review establishes composition and observable state changes, **not exact easing, frame rate, physical-device smoothness or comfort for all users**. DES’s mobile wheel sequence initially did not scroll; a touch-specific pass reached the content. The intervention and its result are preserved. This prevents an automation mismatch from becoming a false design finding.

The seven dossiers and [motion register](motion.md) identify the motion purpose, attention change, feeling hypothesis, transfer rule and evidence boundary for each reference. We have not treated an award, an enabled preference flag or a saved video as a quality pass.
