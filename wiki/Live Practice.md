# Live Practice

## Definition

Live Practice is GTOP's real-time or event-like practice area. It includes hosted Live Quiz experiences and lighter Quiz Run experiences that make MCQ preparation feel social, timely, and competitive.

Its product value is motivation and participation, not real-time mechanics by themselves.

## Why It Matters

GTOP needs repeated student usage before advanced analytics and feedback can become meaningful. Live modes can create energy that ordinary solo practice may not always create: urgency, peer presence, teacher-led moments, and a reason to return.

The product risk is fragmentation. If live modes feel disconnected from review, reports, retry, and diagnosis, they may increase activity without improving learning clarity.

## Current GTOP State

The existing product context distinguishes Live Quiz and Quiz Run. Live Quiz is host-oriented and fits teacher or admin-led events. Quiz Run is lighter and should feel more suitable for everyday or peer-oriented practice.

Both modes should be understood as ways to feed the same [[Practice Loop]], not as separate learning products.

## Boundaries And Non-Goals

Live Practice should not compete with GTOP's core identity as structured MCQ practice. It should not make students choose between "fun live mode" and "serious learning mode." The finish should still support review, reporting, retry, and eventual [[Learning Diagnosis]].

This wiki page should not define session mechanics, host controls, routing, or state handling. Those belong in technical documentation and implementation plans.

## Relationship To Other Concepts

[[Practice Loop]] is the parent learning model. [[Product Direction]] explains why live activity should create useful practice signal. [[Learning Diagnosis]] can benefit from live attempts only if their results remain interpretable. [[Question Bank Quality]] still determines whether live questions deserve trust.

## Decision Guidance

When shaping Live Quiz or Quiz Run, GTOP should make clear who starts the activity, who participates, what makes it live or run-like, and how the result helps the student continue practicing. If the mode cannot feed review or next-practice guidance, it should stay secondary.
