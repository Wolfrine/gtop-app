# GTOP visual next steps

Status: proposal only; not implemented in the current production promotion.

## Founder assessment
The previous version was 2/10 for visual appeal; the reviewed version is 5–6/10. It is effective and working, and authorized for release, but far from the intended visual quality. The next pass should earn a stronger response through its interface rather than explain why it is good.

## Proposed sequence

| Order | Change | Concrete direction |
| --- | --- | --- |
| 1 | Remove unnecessary narration | Audit slogans, eyebrow headings, repeated hints and introductory sentences. Prefer 'Recent practice' over 'Every attempt counts' and 'Results' over 'See what clicked'. Keep instructions that resolve a real choice, and preserve a natural human tone. |
| 2 | Improve the dashboard composition | Reclaim the oversized banner space; make practice modes and recent progress immediately recognisable. Use illustrated actions and deliberate size differences so the screen works at a glance. Preserve existing destinations and handlers. |
| 3 | Create stronger imagery | Develop one coherent illustration family for quick practice, custom practice, group quizzes and Learning Lab. Use subject imagery only where the page already has that subject context. Judge imagery at actual phone size and avoid generic stock decoration. |
| 4 | Add restrained motion and detail | Refine press/hover feedback, answer selection, progress changes and result reveal. Keep question reading steady, respect reduced-motion preferences and check loading cost. Memorable moments should come from craft and responsive feedback. |
| 5 | Extend the accepted language | Carry the chosen treatment into Progress, Custom Quiz, profile, Learning Lab entry and public landing. Give pages their own purpose within the shared system. |

## First checkpoint
Start with one dashboard revision that combines the copy reduction, composition and imagery changes. Show desktop and phone views beside the released version, then judge visual appeal, immediate comprehension and ease of starting a quiz. Keep the existing 9/10 ambition; do not quietly lower it or infer it from task completion.

## Boundaries
This is a proposal, not authorization to begin another redesign in this release. Continue small, reversible changes with the existing interaction checks once the next work is accepted. Keep scoring, account access, saved results, permissions and question-bank content outside the visual scope. Existing loading and Last Score issues remain separately recorded.
