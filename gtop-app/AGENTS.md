# AGENTS.md

Scope: `gtop-app/`

## Build Check

- Run `npm run build -- --configuration production` in `gtop-app/` after changes.

## GT Ecosystem Rules

- Preserve GTOP as a standalone product.
- Hub integration should remain contract-based through URL parameters and return paths.
- When touching quiz launch or summary flows, preserve:
  - `returnTo`
  - `hubReturnPath`
- Do not hardwire Hub-specific assumptions deeper than the integration boundary.

## Data And UX Rules

- Avoid incidental edits to `src/assets/syllabus/index.json`; it is generated by the build pipeline.
- Keep admin and learner flows separate.
- If a change affects reporting or quiz result behavior, verify it against the existing production-oriented user journeys in this repo.
- For visual work, follow root `AGENTS.md`, Central `design/EXECUTION_ROUTING.md`, and local `design/` memory.
- Any UI change needing visual judgment must be inspected in the running app on desktop and mobile-sized viewports; correct known material defects and rerender before calling it complete.
- Do not treat a successful Angular build as evidence that layout, interaction, responsiveness, or visual quality is correct.
