# Features

## Summary

GTOP's feature set is organized around practice, review, content management, and live participation.

## Authentication And Profile Setup

Google-based sign-in and profile setup establish the student's board and standard. This gives GTOP the context needed to filter syllabus and practice experiences.

## Quick And Custom Quiz Practice

Quick Quiz supports low-friction practice by selecting available MCQs automatically. Custom Quiz supports deliberate practice by letting users filter by board, standard, subject, chapter, and question count.

Together, these modes serve both spontaneous practice and targeted revision.

## Quiz Summary, Reports, And Retry

Summaries and reports close the practice loop. They let students review correctness, inspect past attempts, and retry all questions or only incorrect ones.

This area should be treated as core learning infrastructure, not just post-quiz display.

## Question Flagging

Question flagging lets students report potential MCQ issues and gives admins a signal for content review. It connects learner feedback to content quality.

## Admin Content Tools

Admin tools manage MCQs, syllabus combinations, user roles, logs, and live quiz hosting. These tools support the quality and operations layer behind the student experience.

## Live Quiz And Quiz Run

Live Quiz supports hosted real-time quiz events. Quiz Run is a lighter competitive mode that reuses live quiz infrastructure for peer-oriented practice.

The product distinction matters: Live Quiz is admin/host-oriented; Quiz Run should feel easier for everyday participation.
