# Open Questions

## Summary

These questions should shape future GTOP product planning and wiki updates. They are deliberately not execution tasks; PM handoff should carry ownership, scheduling, and implementation planning.

## Institute Admin Definition

What should an Institute Admin do in GTOP, and how is that role different from the current admin/teacher role?

## Student Progress Model

Should GTOP define a stronger product model for mastery, weak areas, streaks, assignments, or recommended next practice beyond current reports and retries?

What minimum student activity is needed before personalized recommendations become reliable enough to show?

How should GTOP encourage consistent student usage so analytics and feedback features have enough signal?

How should GTOP avoid overclaiming [[Learning Diagnosis]] when the student's attempt history is thin?

What should GTOP show when diagnosis evidence is weak: simple review prompts, practice encouragement, low-confidence hints, or no recommendation?

## Student Pulse Definition

How often should [[Student Pulse]] run, and what should trigger it?

Should the first Student Pulse version be text-first, template-based, or image-card based?

What should Student Pulse include so it improves learning rather than becoming a decorative report?

What confidence rules should prevent Student Pulse from overstating recommendations?

## Question Bank Enrichment Model

Which boards, standards, subjects, chapters, and topics already have enough verified content?

What criteria define a verified question for GTOP?

Which metadata fields should be required or optional for question type, pattern, topic tagging, difficulty, and source/status?

How should topic tagging be structured so it helps weak-area diagnosis without becoming too complex to maintain?

How should GTOP resolve the public 50,000+ MCQ claim versus the raw discussion's roughly 1.2 lakh question-bank reference?

## Comprehensive Curriculum Coverage

Which board/programme, language or medium variants, and examination cohorts must be distinguished to fulfil the founder's comprehensive syllabus goal? How should admins review school-selected or locally adapted curricula when there is no single board-wide chapter list for a standard?

What source evidence establishes subject completeness, and how should conflicting editions or official revisions be presented for human review? These uncertainties should remain visible within [[Question Bank Quality]].

## Live Quiz Versus Quiz Run Positioning

How should [[Live Practice]] explain the difference between hosted Live Quiz events and peer-oriented Quiz Runs so students and admins choose the right mode?

How should live results flow back into review, retry, reports, and next-practice guidance so live activity strengthens the [[Practice Loop]]?

## Admin Content Quality Workflow

What should happen after students flag questions? GTOP has the signal, but the ideal review workflow, prioritization, and resolution states need product definition.

Which [[Question Bank Quality]] signals should admins see first: coverage gaps, flags, stale questions, repeated wrong answers, or missing topic tags?

## Growth Tutorials Ecosystem Relationship

How much should GTOP expose Hub return paths, Growth Tutorials branding, or cross-product navigation without weakening its independence as a standalone product?

## AI-Native Education Direction

What future education patterns should GTOP prepare for over the next decade?

How should GTOP differentiate against AI-native education tools while preserving its MCQ practice strengths?

Where should GTOP use AI directly in the student experience, and where should AI remain behind the scenes for content enrichment, review, or product analysis?

How should GTOP balance MCQ exam readiness with broader AI-era learning skills?
