# Open Questions

## Summary

These questions should shape future GTOP product planning and wiki updates.

## Institute Admin Definition

What should an Institute Admin do in GTOP, and how is that role different from the current admin/teacher role?

## Student Progress Model

Should GTOP define a stronger product model for mastery, weak areas, streaks, assignments, or recommended next practice beyond current reports and retries?

What minimum student activity is needed before personalized recommendations become reliable enough to show?

How should GTOP encourage consistent student usage so analytics and feedback features have enough signal?

## Student Pulse Definition

How often should Student Pulse run, and what should trigger it?

Should the first Student Pulse version be text-first, template-based, or image-card based?

What should Student Pulse include so it improves learning rather than becoming a decorative report?

## Question Bank Enrichment Model

Which boards, standards, subjects, chapters, and topics already have enough verified content?

What criteria define a verified question for GTOP?

Which metadata fields should be required or optional for question type, pattern, topic tagging, difficulty, and source/status?

How should topic tagging be structured so it helps weak-area diagnosis without becoming too complex to maintain?

## Live Quiz Versus Quiz Run Positioning

How should the product explain the difference between hosted Live Quiz events and peer-oriented Quiz Runs so students and admins choose the right mode?

## Admin Content Quality Workflow

What should happen after students flag questions? GTOP has the signal, but the ideal review workflow, prioritization, and resolution states need product definition.

## Growth Tutorials Ecosystem Relationship

How much should GTOP expose Hub return paths, Growth Tutorials branding, or cross-product navigation without weakening its independence as a standalone product?

## AI-Native Education Direction

What future education patterns should GTOP prepare for over the next decade?

How should GTOP differentiate against AI-native education tools while preserving its MCQ practice strengths?
